# ГраМетч

Сайт у стилі Тіндера, тільки для ігор: свайпаєш вправо — «граю», вліво — «не моє», вгору — «дуже хочу».

- 2016 ігор зі Steam: назва, рік, опис, обкладинка, режими й жанри
- Розділи: мультиплеєр, кооп, соло, VR і 55 жанрів
- Три мови інтерфейсу й описів: українська, англійська, російська
- Метчі зберігаються у браузері

Сайт статичний: `index.html`, `styles.css`, `app.js`, `i18n.js` і дані в `data/`.

## Як оновити базу ігор

Потрібен Python 3. Скрипти лежать у `tools/`:

```bash
python tools/fetch_steam.py      # список ігор зі SteamSpy і деталі з API Steam (en/uk/ru)
python tools/build_data.py . 2000 # збирає data/games.js і data/desc.*.js
python tools/translate.py        # машинний переклад описів, яких немає потрібною мовою
python tools/check_desc.py .     # перевіряє, що кожен опис написаний своєю мовою
```

Обкладинки й описи ігор належать їхнім власникам і завантажуються з Steam.
